QUICK ANSWERS

What beginners usually need to know.

Do I need a terminal?

No for the normal Windows flow. Advanced controls remain available when you need them.

Can it silently switch to a paid provider?

No. $0 Mode blocks routes whose cost status is not verified for the current setup.

What if the agent stops halfway?

FirstWindow keeps checkpoint and resume state so you can continue instead of starting over.

UNDER THE HOOD

FirstWindow is the control surface, not another coding model.

Hermes Agent executes. Agnes API can be the cloud provider lane, while a validated Hermes Managed Local model can be the local lane.
